# Mac で試すときのチェックリスト

ずんだもんジャーヴィス（zundamon-jarvis）を Mac に入れて、ひととおり動くか確かめるための手順です。
上から順に進めて、各手順の「こうなれば OK」と同じになるかを見てください。
うまくいかないところがあれば、そこで止めて、最後の「うまくいかないとき」の手順で様子を送ってください。

## はじめに用意するもの

- **Apple シリコンの Mac**（M1 以降）。Intel の Mac では動きません
- **macOS 14（Sonoma）以降**。音声まわりの部品（onnxruntime）が macOS 14 以降にしか対応していないためです。
  バージョンは  メニュー > 「この Mac について」で確かめられます
- **Claude の有料プラン**と、**Claude Code**（ターミナルで `claude` と打つと起動するもの）。
  先に一度 `claude` を起動してログインしておいてください
- **ディスクの空き 8 GB 以上**（声のエンジンと文字起こしのモデルで数 GB 使います）
- **ヘッドホンかイヤホン**（おすすめ）。Mac のスピーカーだと、ずんだもんの声をマイクが拾ってしまうので、
  しゃべっている間は聞き取りを止めます。そのため途中で割り込めません

## 1. インストール

ターミナル（アプリケーション > ユーティリティ > ターミナル）を開いて、次の 1 行を貼り付けて Enter を押します。

```sh
curl -fsSL https://raw.githubusercontent.com/dyoshyy/zundamon-jarvis/main/install.sh | sh
```

`==> …` という行が順に出て、ダウンロードが進みます（はじめは 10〜20 分ほどかかります）。
途中で止まった場合は、同じ 1 行をもう一度実行すれば、終わったところは飛ばして続きから進みます。

最後に設定の質問（`zundamon-jarvis setup`）が始まります。

1. Claude にログインできているかの確認（自動）
2. マイクの確認。**「"ターミナル" がマイクへのアクセスを求めています」と出たら「許可」**を押して、Enter を押してください
3. ヘッドホンの案内
4. 声選び。番号を入れると試しに読み上げます。気に入ったら `y`、Enter だけなら今のまま
5. 知識フォルダ（メモのフォルダなど。なければ Enter で飛ばして大丈夫です）
6. Claude のモデル（Enter で `sonnet` のまま）
7. 常駐の設定と起動。起動したあと、**「"python3.12" がマイクへのアクセスを求めています」と出たら「許可」**を押して、
   何か話しかけてください（常駐しているほうは、ターミナルとは別に許可が要ります。"python3.12" がその本体です）

**こうなれば OK**：最後に「常駐しているほうにも音が届いています。」「話しかけてみてください。」と出て、
画面上のメニューバーに ▶ のアイコンが出る。

> 「Claude にログインできていません」と出て止まったら：ターミナルで `claude` を実行してログインしてから、
> もう一度 `zundamon-jarvis setup` を実行してください。
>
> 「音が取れませんでした」と出たら：システム設定 > プライバシーとセキュリティ > マイク で
> 「ターミナル」をオンにしてください。設定はそのまま続きます。
>
> 「常駐しているほうにマイクの音が届いていません」と出たら：同じ画面で「python3.12」をオンにしてください。
> 一覧にないときは、画面に出る 2 行（`tccutil reset Microphone` と `launchctl kickstart …`）を実行してから、
> Enter を押してもう一度確かめます。

## 2. ヘッドホンで話しかける

ヘッドホンをつけて、ふつうの声で話しかけます（例：「今日は何曜日？」）。

**こうなれば OK**：メニューバーのアイコンが ▶ →（考え中）⏳ →（話し中）🔊 と変わり、
ヘッドホンから返事が聞こえる。返事が終わると ▶ に戻る。

## 3. 割り込む

少し長めの返事になる質問をして（例：「日本の歴史を順番に説明して」）、話している途中で話しかけます。

**こうなれば OK**：ずんだもんの声がすぐ止まり、こちらの話を聞いて、それに答える。

（Mac のスピーカーで鳴らしているときは割り込めません。これは正常です。）

## 4. メニューバーから一時停止／再開

メニューバーのアイコンをクリックして **Pause** を押します。そのあと話しかけてみて、もう一度 **Resume** を押します。

**こうなれば OK**：Pause のあとアイコンが ⏸ になり、話しかけても反応しない。
Resume で ▶ に戻り、また話を聞くようになる。

## 5. 会話ウィンドウ

メニューバーのアイコンから **Conversation…** を押します。

**こうなれば OK**：ターミナルのウィンドウが開き、聞き取った言葉（`You ▸ …`）と返事が流れていく。
もう一度 Conversation… を押すと閉じる。

## 6. 設定ウィンドウ（速さ・声）

メニューバーのアイコンから **Settings…** を押します。↑↓ で行を選び、←→ で変えます。

- **Voice speed**：←→ で話す速さを変える
- **Voice**：Enter で声の一覧を開き、↑↓ で選ぶと試しに読み上げ、Enter で決定
- Esc（または q）で閉じる

**こうなれば OK**：速さを変えると、その速さで短く読み上げる。声を選ぶと、その声で試しに読み上げ、
決めたあとの返事はその声になる。

## 7. 再ログイン後の自動起動

 メニュー > ログアウト（または再起動）して、もう一度ログインします。

**こうなれば OK**：ログインして少し（1 分ほど）待つと、メニューバーに ▶ のアイコンが出て、
話しかけると返事がある。自分で何かを起動する必要はない。

---

## アイコンの見かた

| アイコン | 意味 |
|---|---|
| ▶ | 聞いています |
| ⏳ | 考えています |
| 🔊 | 話しています |
| ⏸ | 一時停止中 |
| ⛔ | Claude の利用上限に達しました（時間をおくと戻ります） |
| 📴 | マイクか声のエンジンが使えません（メニューを開くと理由が出ます） |
| 💤 | 本体が動いていません |

## うまくいかないとき

- メニューバーが 📴 で、メニューに「マイクが使えません」と出る：システム設定 > プライバシーとセキュリティ > マイク で
  「python3.12」をオンにしてください（ターミナルを許可しただけでは、常駐しているほうは聞こえません）

ターミナルで次を実行すると、様子をまとめたもの（診断結果）がクリップボードにコピーされます。

```sh
zundamon-jarvis doctor | pbcopy
```

それをメッセージに貼り付けて、**どの手順で、何をしたら、どうなったか**をひとこと添えて送ってください。

診断結果には Mac と各部品のバージョン、マイクの一覧、動作の状態、最近のログが入ります。
送る前に自動で伏せ字にしてあります：ホームフォルダの場所は `~`、ユーザー名・名前は `<user>`、
コンピュータ名は `<host>`、メールアドレスは `<email>`、知識フォルダの場所は `<knowledge_dir>` に置き換えています。
会話の中身（聞き取った言葉、返事、声のエンジンに渡した文、確認の質問）は `…` にしています。
ただし、エラーの説明文などに思わぬ言葉が混じることは考えられるので、気になる場合は、貼り付ける前に中身を見て消してもらってかまいません。

## 外したいとき

```sh
zundamon-jarvis uninstall
```

常駐を止めて自動起動を外し、声のエンジンと設定を消すかを聞きます。最後に本体を外すコマンドが出ます。
